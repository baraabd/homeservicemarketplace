# Sprint 13 Definition of Done

Done means implemented, integrated and evidenced—not designed. Required: Prisma schema and migration agree; fresh DB + upgrade rehearsal pass; plan/version/entitlement/coupon/payment-intent/subscription/ledger repositories and transactional services exist; provider/admin APIs enforce RBAC/CSRF/IDOR and idempotency; provider/admin UX is responsive EN/AR/RTL and accessible; unit/integration/concurrency/E2E tests cover acceptance matrix; existing product tests remain green; final-SHA CI, CodeQL, dependency/secret, Docker and drift gates are green; no High/Critical open; live payment configuration remains disabled.

Until every condition is satisfied, status remains IN PROGRESS regardless of documentation volume or partial green checks.
