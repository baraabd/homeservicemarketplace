## موانع الدمج والتفعيل القائمة

1. **الوصول للاستضافة:** لم يتوفر اتصال مصادق إلى Vercel أو Railway؛
   لم تُتحقق IDs أو الدومينات أو الموارد الحية أو billing أو حالة Pause.
2. **الأمان:** بقيت تنبيهات أدوات التطوير في deepmerge/minimatch/glob.
   لم تُضعف سياسة audit أو تُخفَ التنبيهات أو تُفرض major overrides غير مختبرة.
3. **Windows:** كان فحص Web startup عند قاعدة العمل يفشل بعد إعادة تحميل
   صفحة admin؛ لا يوجد دليل يسمح باعتبار تحديث Vite علاجًا له.
   يجب قبول أحدث نتائج CI على رأس طلب السحب قبل الدمج.
4. **CD الخلفي:** المسار الجديد يتحقق من API جاهز على SHA المطلوب.
   لا ينشر Railway ولا ينشئ الموارد ولا يشغّل migrator؛ يلزم ربط الخدمات
   الفعلية لتصميم وتنفيذ هذا الجزء والتحقق منه.
5. **البيانات والقبول:** لم تُفحص قاعدة البيانات القديمة أو backups ولم
   تُنفذ migrations أو رحلات login/OTP/refresh/upload/booking/WSS المستضافة.
