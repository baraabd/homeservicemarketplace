# R17 — Gap register

Baseline `develop@460b9ee`. Classes: `ALREADY_ACCEPTED`,
`IMPLEMENTED_EVIDENCE_MISSING`, `DEMONSTRATED_DEFECT`,
`MISSING_APPROVED_BEHAVIOR`, `POLICY_BLOCKED`, `OUT_OF_SCOPE`.

Evidence column: **reproduced** (a failing test against the untouched
baseline), **source-confirmed** (the cited code was read and does what is
stated; no failing test yet), **reported** (found by inventory, not yet
re-read). A defect is only treated as demonstrated once reproduced; the unit
that owns it reproduces it before changing code.
