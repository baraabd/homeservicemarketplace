# R17-B — Notification authority matrix

Path from business action to persisted read state, after R17-B. Evidence
levels as in `AUTHORITY_MATRIX.md` (U unit, I real PostgreSQL integration,
B real browser + real API + DB, X two API processes, T real Socket.IO client).

| Stage                 | Owner                                                                                                                                                           | Mechanism                                                                                                                             | Evidence                                                                |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| Business event        | domain service, in its transaction                                                                                                                              | e.g. `ProviderBookingsService.transition`                                                                                             | existing suites                                                         |
| Notification row      | `NotificationsService.createForUser(input, tx)`                                                                                                                 | INSERT in the caller's transaction (or a local one)                                                                                   | U, I                                                                    |
| Dispatch intent       | same call                                                                                                                                                       | `OutboxEvent` `notification.created`, `dedupeKey notification.created:{id}`, same transaction                                         | U, I                                                                    |
| Batch writers         | `RequestAvailableBatchHandler` (`createMany`), dispute workspace/intake, provider review, verification case                                                     | already inside outbox handler or domain transactions; announce in `afterCommit` (dispute, review, request) or not live (verification) | existing I suites (R07 batch rollback, dispute workspace)               |
| Dispatch              | `OutboxWorker` (any replica): `FOR UPDATE SKIP LOCKED` claim, lease reclaim, `OutboxHandlerRun` marker in the handler transaction                               | `NotificationCreatedHandler` re-reads the live row; publishes in `afterCommit`                                                        | I (once, re-delivery skipped, reclaimed lease, deleted-before-dispatch) |
| Transport             | `RealtimeEventsPublisher` → in-process bus (SSE) + Socket.IO room `user:{id}` via Redis adapter                                                                 | only when `REALTIME_SOCKET_IO=true` (default false)                                                                                   | T across replicas C→D                                                   |
| Client cache          | React Query (`seeker`, `provider`, `admin` keys); polling 15–20 s; cleared by `clearAuthSession` on login, logout, expiry, credential reset, cross-tab sign-out | unchanged                                                                                                                             | B (account switch)                                                      |
| Visible inbox / badge | seeker `NotificationDrawer` + `ProfileTab`; provider `ProviderNotifications`; admin `AdminNotificationsBell`                                                    | server count; honest loading / error / stale / empty                                                                                  | U, B                                                                    |
| Read mutation         | `POST /:id/read`; `POST /read-all?experience` `{ids}`; `DELETE /:id`                                                                                            | owner + scope + live + unread conditions in one `updateMany`                                                                          | U, I, B, X                                                              |
| Read-back             | `GET /`, `GET /unread-count` (both scoped)                                                                                                                      |                                                                                                                                       | I, B, X                                                                 |

## Authorization

| Operation    | Rule                                                | Negative evidence                                                                               |
| ------------ | --------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| list / count | session user's rows only; experience filter         | I (another user sees none with `experience=admin`)                                              |
| mark one     | 404 for foreign, deleted, unknown                   | B (provider marking the seeker's row → 404 on replica B)                                        |
| read-all     | only own, live, unread, in-scope rows among the ids | I (foreign/other-scope/deleted/unknown ignored), B (provider read-all with the seeker's id → 0) |
| delete       | own live row only, 404 otherwise                    | existing U/E                                                                                    |
| dispatch     | server-only (outbox); no HTTP create surface        | —                                                                                               |
