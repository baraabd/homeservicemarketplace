# R17-D — Admin operations authority matrix

Base `develop@aaf30aa` plus the R17-D changes. Every mutation runs in one
`TransactionRunner` transaction (Prisma 6.12.0: a rejected COMMIT rejects the
caller, per PLATFORM-TX-1).

Classes: **AUTHORITATIVE** (server decides, persists, audits, reads back);
**READ_ONLY_BY_DESIGN**; **PLACEHOLDER**; **BROKEN**; **POLICY_BLOCKED**;
**EVIDENCE_MISSING**. "Before" is the class at `aaf30aa`.

Test levels: **U** unit; **E** API e2e with a stubbed service; **H** real
AppModule over HTTP with real login, guards and CSRF; **B** real browser plus
real API and database.
