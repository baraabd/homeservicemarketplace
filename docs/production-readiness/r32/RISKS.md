The current linked STANDARD compensation model requires the accepted original
two-entry subscription posting layout. An unexpected historic layout fails
closed; R32 does not invent an allocation. A confirmed failure must be an
authoritative bound terminal result, never a timeout or unverified absence.

R16 provider payout decisions remain blocked. Subscription revenue is not
provider earnings, escrow or withdrawable funds. Plan purchase/refund grants
no identity verification, legal eligibility or work access. R18 blockers and
existing production verification policy are untouched.
