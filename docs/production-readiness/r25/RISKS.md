| Risk                                                                   | Control in this lane                                                                                                   | Acceptance limit / owner action                                                                                           |
| ---------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Missed transient revocation event                                      | Recheck original JTI/session/expiry and current recipient authority for delivery; bounded periodic revalidation        | Verify the combined candidate against real IAM actions; no reliance on a Redis eviction announcement alone                |
| Private messages survive permission changes                            | Current participant/provider capability gate before subscription and delivery; client private-query resync/removal     | Membership/role/capability authority remains in existing repositories and services                                        |
| Redis Pub/Sub loses reconnect-gap events                               | PostgreSQL history and read state remain authoritative; REST resync on reconnect/failure                               | No durable replay/cursor guarantee is attributed to classic Redis adapter                                                 |
| Slow reader, dependency or broker retains work                         | Explicit connection/room/payload/publication/delivery/SSE bounds and deadlines                                         | Local declared workload is not hosted saturation or capacity acceptance                                                   |
| Long-polling spans API replicas without affinity                       | Polling support is conditional on edge affinity; default web transport is WebSocket                                    | Real deployed edge affinity, TLS/cookies and idle timeouts must be verified before enabling polling                       |
| Reconnect storm or duplicated visible alert                            | One bounded jittered reconnect scheduler; wait for authorized ack; bounded replay/watermark and cross-tab coordination | Unsupported cross-tab primitives degrade to history/badges; delivery remains best effort with authoritative REST recovery |
| Total Redis outage disables REST limiter                               | Fail-closed policy retained                                                                                            | Safe 429 is not called successful polling; restore Redis and prove resync                                                 |
| Existing shared test fixtures no longer match stricter socket contract | Concrete CR-001 fixture patches retain all prior assertions                                                            | R25 has no shared-path lease; coordinator applies changes and reruns the combined source                                  |
| New real browser spec leaks into mock CI                               | Explicit dedicated runner flag and concrete Playwright/CI routing request                                              | Draft PR remains integration pending until coordinator applies routing                                                    |
| Stale/partial evidence is called current                               | Clean committed source required before/after run; full compiled API directory hash; positive non-skipped report counts | Publish final source/tree separately from source-specific acceptance evidence                                             |
| Diagnostics expose sessions or synthetic identity                      | Private logs and browser outputs; fixed-schema public metrics; screenshot review                                       | Never upload raw DB URLs, cookies, JWTs, mailbox exports, traces or video                                                 |
| Ownership conflict with parallel Wave 2 lanes                          | Exact 39 owned paths + two infrastructure lease paths; one writer per group                                            | Shared IAM/config/workflow/registry changes serialized by coordinator                                                     |

No money movement, provider eligibility rule, admin permission grant, schema, dependency, central registry or production configuration is changed. Production transport activation requires a separately approved hosted rollout. The source changes can be rolled back without rewriting durable message or notification history.
