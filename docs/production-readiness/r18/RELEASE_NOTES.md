# Release notes — version 1 candidate (draft)

Draft. No release candidate has been built or tagged (`GO_NO_GO.md`), and the
repository has no tags yet. When one is built, the first candidate is named
`v1.0.0-rc.1`.

## Included (subject to `RELEASE_SCOPE.md` approval)

- Seekers: sign-up with email verification, sign-in, recovery; profile and
  addresses; service catalog; requests with verified photos and video; bid
  comparison and acceptance; bookings with a recorded timeline; booking
  messaging; in-app notifications; one review per completed booking;
  disputes (once the owner sets the dispute windows); help and support
  tickets.
- Providers: upgrade and guided onboarding (services, work area, working
  hours, identity verification, correction and resubmission); available
  requests; bids, withdrawal and My Bids across every page; bookings, start
  and completion; messaging; notifications; profile, portfolio and
  reputation; a read-only view of completed booking values.
- Admins: provider review with private evidence access, correction,
  approval and rejection; portfolio moderation; users, settings, analytics,
  audit, disputes and support.
- Arabic (RTL) and English (LTR).

## Not included

No payment, checkout, refund, escrow, payout, withdrawal or bank transfer;
no live provider location; no in-app calls. Earnings shown to providers are
booking values, not a balance.
